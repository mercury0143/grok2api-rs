存储管理

配置媒体文件（图片/视频）的存储方式。

存储类型

本地存储配置

媒体文件存储的基础目录路径（相对于项目根目录）

S3 / MinIO 配置

留空使用 AWS S3，填写自定义 endpoint 使用 MinIO 或其他 S3 兼容服务

使用直链模式时，将使用此域名生成文件 URL

上传文件时的路径前缀，如 "grok/" 会将文件存储在 Bucket 的 grok/ 目录下

勾选后返回 S3 直链，否则返回项目代理 URL

配置优先级说明：

  • 通过 API 保存的配置会持久化到 data/config.toml
  • 启动时优先使用持久化配置，其次使用默认配置
  • 修改配置后需要重新上传文件才会使用新的存储方式
  • 已上传的文件不会自动迁移，需要手动处理
